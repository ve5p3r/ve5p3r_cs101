# Number Guessing Game

CS101 C study exercise. This is an authored practice draft for review, not a recovered instructor solution or a submitted assignment. Check against the actual course prompt before using it for submission.

## Build and run

```sh
cc -std=c11 -Wall -Wextra -Wpedantic number_guessing_game.c -o number-guessing-game
./number-guessing-game
```
